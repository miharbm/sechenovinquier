\section*{Аннотация}

Пациенту, который недавно перенес инфаркт миокарда, требуется контроль за его здоровьем.
Для этого их периодически нужно опрашивать о самочувствии.
Сейчас практикуется опрос пациентов при помощи обзванивания их при помощи телефонной сети.
Каждый звонок врач проводит по заранее заготовленному скрипту.
На них врач тратит очень много времени, поэтому есть запрос об оптимизации рабочего времени врача.
В качестве решения было предложено перенести этот скрипт в платформу, которая будет собирать данные с пациентов при помощи мобильного приложения.
