\chapter*{Заключение}
\addcontentsline{toc}{chapter}{Заключение}
\label{sec:3}

Создано Веб-приложение как часть платформы для врачей и пациентов для мониторинга состояния пациентов, перенесших инфаркт, с помощью динамических опросов.
Врачи способны в нем регистрировать пациентов, анализировать их ответы.
Пациенты могут проходить опросы на любом устройстве
Приложение адаптирование для использования на мобильных устройствах.
Также оно доработано под PWA, чтобы решить проблему создания нативных приложений и получения PUSH-уведомлений для напоминания о прохождения опроса под iOS в России.
Приложение отправлено в бета-тестирование и собирается обратная связь.
